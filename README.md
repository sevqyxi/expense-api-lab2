# Лабораторна робота №2

**Дисципліна:** Технології розроблення серверних компонентів

**Тема:** Проєктування базового RESTful API (In-Memory) та використання Bruno для тестування запитів.

## Опис

У лабораторній роботі реалізовано REST API для обліку витрат за допомогою Python та FastAPI.

У системі є 3 сутності:
- User — користувачі
- Category — категорії витрат
- Record — записи про витрати

Дані зберігаються у словниках Python, без використання бази даних. Після перезапуску сервера всі записи видаляються.

## Запуск проєкту

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Після запуску:

- API: http://127.0.0.1:8000
- Swagger: http://127.0.0.1:8000/docs

## Основні можливості

Реалізовано створення, перегляд та видалення користувачів, категорій і витрат.

Також є фільтрація витрат за `user_id` та `category_id`.

Для запитів використовуються HTTP-методи GET, POST і DELETE. Передбачено обробку помилок із кодами 400 та 404.

Якщо виконати `GET /record` без параметрів фільтрації, сервер поверне помилку 400.

## Тестування через Bruno

Для перевірки API використовується Bruno.

1. Запустити сервер.
2. Відкрити Bruno.
3. Через Open Collection вибрати папку `bruno_collection`.
4. Вибрати середовище Local.
5. Запускати окремі запити через Send або всю колекцію через Runner.

У колекції є запити для створення, отримання та видалення даних, а також для перевірки обробки помилок.

## Структура проєкту

- `main.py` — реалізація API
- `requirements.txt` — залежності
- `bruno_collection/` — запити для тестування
- `README.md` — опис роботи та інструкція запуску
